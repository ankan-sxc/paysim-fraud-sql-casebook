# PaySim Fraud & Risk Analytics — SQL Casebook

## Project Overview

An advanced SQL portfolio project focused on transaction monitoring, fraud detection, account-level risk analysis and financial crime investigation using PostgreSQL and the PaySim synthetic mobile money transaction dataset.

## Objectives

- Identify suspicious transaction patterns.
- Compare fraudulent and legitimate transactions.
- Analyze account-level transaction behaviour.
- Detect unusual transaction velocity and high-value activity.
- Build investigator-oriented SQL queries.
- Translate analytical findings into fraud-risk insights.

## Technical Stack

- PostgreSQL
- SQL
- Common Table Expressions (CTEs)
- Window Functions
- Subqueries
- Aggregations
- CASE WHEN
- Fraud & Risk Analytics

## Dataset

PaySim — synthetic mobile money transaction data.

The raw dataset is not included in this repository. Download it from [Kaggle – PaySim](https://www.kaggle.com/datasets/ealaxi/paysim1).

## Repository Contents

- `Advanced_Practice_PaySim_Fraud_Risk.sql` — advanced SQL practice and fraud investigation queries.
- `Question Set.pdf` — contains the question that are implemented here. Here I didn't attempt the Beginner Level Question


## Disclaimer

PaySim is a synthetic dataset. Analytical findings are intended for educational and portfolio purposes, not production fraud decisions.
